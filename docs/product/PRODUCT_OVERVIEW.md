# Ryvix Product Overview & Capabilities

## 1. Product Mission & Positioning

Ryvix is an **AI-powered autonomous software and infrastructure operations platform**. It bridges the gap between software development and production infrastructure operations by combining an intelligent reasoning engine with safe, controlled execution connectors.

Modern engineering teams spend significant time context-switching between code editors, GitHub PRs, terminal shells, cloud consoles, monitoring dashboards, and incident alert channels. Ryvix unifies these domains into a single autonomous operator that can be commanded via Web Chat, WhatsApp, or Gmail.

---

## 2. Core Value Pillars

### 1. Autonomous Coding & Safe Verification
- Understands existing software codebases across diverse technology stacks.
- Translates natural-language requests into precise code modifications.
- Tests modifications in isolated ephemeral workspaces before human approval.
- Generates live frontend previews for visual verification prior to commit or deployment.

### 2. Dual-Path Infrastructure Operations & Resilience
- Monitors in-host operating system health, systemd services, container states, and logs via a lightweight internal connector.
- Maintains an independent, out-of-band external control path to detect catastrophic server failures and perform authorized cloud recovery (e.g. rebooting a frozen virtual machine).

### 3. High-Signal Telemetry & Forensic Investigation
- Collects and correlates metrics, logs, and deployment events in real-time.
- Employs deterministic anomaly detection to catch spikes and attacks immediately, backed by AI models to investigate root causes and explain incidents in plain English.

### 4. Omnichannel Communication & Control
- Accessible wherever the engineering team operates: Web Console, WhatsApp mobile chat for urgent on-call responses, and Gmail for asynchronous task summaries.

---

## 3. Supported Personas

- **Solo Developers & Founders**: Act as an autonomous virtual DevOps engineer and junior developer who can manage deployments, fix bugs, and keep servers online 24/7.
- **Small & Medium Engineering Teams**: Eliminate alert fatigue, speed up routine maintenance, and provide safe, previewed frontend tweaks without manual staging setups.
- **On-Call Site Reliability Engineers**: Triage production outages in seconds directly via WhatsApp during off-hours with one-click recovery approvals.

---

## 4. Key Platform Innovations

### 1. Mem0 3-Tier Cognitive Memory Architecture
- **Short-Term Session Memory**: Ephemeral sliding-window conversation turns and active tool scratchpads.
- **Long-Term Knowledge Store**: Persistent retention of user preferences, repository tech stacks, and past incident solutions.
- **Semantic Vector Associative Memory**: 64-dimensional Float32Array embeddings for sub-millisecond concept retrieval.

### 2. 100% 6-Digit Email OTP Authentication
- Complete deprecation of clickable verification links and magic-link redirect tokens.
- Mandatory 6-digit numeric OTP for New Account Registration, Login, and Password Recovery.
- High-performance Three.js cyberpunk interface with 3D moving blocks and glowing micro-animations.

### 3. Single-Command Self-Training Pipeline
- Deterministic sub-second training (`npm run train:all`) that updates pattern recognizers, neural weights, and knowledge runbooks in ~2.38s.
