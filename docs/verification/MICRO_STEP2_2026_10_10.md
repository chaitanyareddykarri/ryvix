checks the resolved mount, default/optional roles, memory limits, non-root/read-only

workflow. The API dependency audit now also rejects `fs/promises` imports.

These five implementation items are locally complete for the restricted trial;
the external evidence column remains pending. This is not full-project or live
deployment completion.

  Publishing is opt-in for main pushes, with revision tags/digests. No host CD
  enabled. Existing ARM pipeline retained for the larger-host configuration.

  bounded RAM, memory+swap, CPU, process limits, log rotation, read-only roots,
  role-specific volumes and environment templates. No public Docker port.
